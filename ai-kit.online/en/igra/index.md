# Give the System a task

Drag a task to a suitable channel: a file to Telegram, email or a folder on the Disk, a request to Telegram, email or voice. On a phone: tap a task, then a channel. Watch how the System hands it out to its tools and where it returns the result.

One System — many channels and tools

The reply comes to Telegram or email, files are placed in a folder on the Disk, reports go to your website. What is included in which tier and how installation goes — step by step in the bot. [The installation path in the bot →](https://ai-kit.online/v-kanal.php?t=b&s=sistema&m=igra)

A diagram game: the files, numbers and deadlines are made up. "Eff." is in the "Whole System", "Add." is optional, for a separate fee.
